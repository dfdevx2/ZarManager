# ZarManager

ZarManager is a high-performance desktop application developed for Linux environments (specifically focused on CachyOS/Arch). Its strict purpose is the structural extraction of the proprietary Xbox 360 file system (XDVDFS) and its subsequent random-access block compression (ZArchive), optimizing preservation libraries for the Xenia emulator.

## Architecture
The system operates through an asynchronous Python backend (Multithreading) integrated with classic C binaries (`extract-xiso` and `zarchive`), overlaid with a responsive graphical interface built via `CustomTkinter` featuring real-time hexadecimal theme injection.
