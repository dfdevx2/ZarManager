# ZarManager v1.2.6 - The "End-to-End" Smart Pipeline Update

We are incredibly proud to announce the biggest architectural update to ZarManager. Version 1.2.6 transforms the application into a robust, high-performance **End-to-End Preservation Suite**.

### 🚀 Major Features & Innovations
* **Built-in 7-Zip Integration:** ZarManager now natively understands `.zip`, `.rar`, `.7z`, `.tar`, and `.gz` archives.
* **Smart "Flat" Extraction:** Automatically extracts core files directly without nesting folders.
* **Collision Detection Engine:** Prompts to Overwrite, Skip, or Cancel when target files exist.
* **Silent Auto-Updater:** Checks for updates in the background without freezing the UI.
* **Cross-Platform Audio Triggers:** Auditory feedback on task completion or failure.

### ⚡ Performance & UI Overhaul
* **Native Treeview Rendering:** Ultra-fast rendering with smooth spacing.
* **New "AMOLED Purple" Theme:** Pure black background with purple accents.
